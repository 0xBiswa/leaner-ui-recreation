# Linear UI Recreation

A frontend recreation of the Linear website homepage, built from scratch using HTML and CSS as part of my **2-Day Website Recreation Challenge**.

> **Educational project. Not affiliated with or endorsed by Linear.**

## 🎯 Purpose

The goal of this project is to improve my ability to:

- Reverse-engineer website layouts
- Structure semantic HTML
- Use BEM-style CSS naming
- Build responsive layouts
- Understand spacing, typography, and visual hierarchy
- Recreate interfaces without copying the original source code

## 🛠️ Built With

- HTML5
- CSS3

## 📚 What I Learned

- Structuring a landing page into reusable sections
- BEM naming conventions
- CSS Flexbox
- CSS Grid
- Responsive design
- Container and spacing systems
- Typography hierarchy
- Component-based thinking
